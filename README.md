# Programación 1
Este reporsitorio contiene los programas y ejercicios desarrolados durante la materia de Programación 1.
Los ejercios están organizados por temas, y cada programa se encuentra en su propia carpeta.
## Programas incluidos
### Blackjack
Un juego de cartas para 2 jugadores.
### Curp
Programa que genera la curp del usuario.
### Figuras
Programa que genera figuras.
### IMC 
Calcula el IMC de un adulto.
